# Code of conduct

dumbtv follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the work. Many
people here are running a terminal for the first time to fix their own TV; help
them the way you would want to be helped.

To report a problem, message the maintainer, [@DevMuzzammil](https://x.com/DevMuzzammil)
on X, write through [dumbtv.org/help](https://dumbtv.org/help), or open a private
report from the repository's **Security** tab. Reports are kept confidential.
