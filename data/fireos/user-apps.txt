# removed only when the owner names it (REMOVE_EXTRA in dumbtv.conf, or
# configure.sh --remove). This list exists so agents and configure.sh know them by
# name; data/apps.txt has readable names for the common ones.

# Named apps are handled by debloat.sh like this: Amazon's own (system) apps are
# disabled, which restore.sh undoes; apps installed from a store are uninstalled
# and come back from the store.
